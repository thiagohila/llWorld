# llWorld

An autonomous world simulation project exploring AI-driven characters,
emergent storytelling, and interactions between LLMs and a simulated world.

## Components

- `worldbox/`: upstream-derived game simulation, maintained as a separate repository.
- `worldbox-ai/`: AI companion and decision-making layer.
- `docs/`: architecture, integration contracts, and development notes.

## Status

Experimental project under active development.
